# PageSim

PageSim is a Linux-based Operating Systems project that simulates
demand paging and page replacement.

## Project

Project 7 - PageSim

### Core Concepts

- Virtual Memory
- Demand Paging
- Page Tables
- Page Faults
- Physical Memory
- Page Replacement
- TLB
- Process Scheduling
- Memory Management

### Planned Algorithms

- FIFO
- LRU
- Optimal
- Clock / Second Chance

### Scheduling

- FCFS
- Round Robin

## Technology

- Language: C
- Operating System: Linux / Ubuntu
- Compiler: GCC
- Build System: GNU Make
- Debugging: GDB
- Memory Checking: Valgrind
